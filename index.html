Booth's Recoding Rules

  • 00 / 11: No arithmetic operation; perform Arithmetic Right Shift (ASHR).
  • 01: End of a string of 1s → AC ← AC + M, then ASHR.
  • 10: Start of a string of 1s → AC ← AC - M, then ASHR.

Array Multiplier Architecture

An N × N combinational array uses N² AND gates to compute all partial product bits PP[j,i] = Mᵢ · Qⱼ simultaneously, summing shifted rows through Half and Full Adders.

Signed Bit Multiplication

Sign-Magnitude computes the output sign via S_out = S_M ⊕ S_Q and multiplies (N-1)-bit magnitudes. Signed 2's Complement sign-extends partial products to 2N bits and subtracts the MSB term (-2ⁿ⁻¹).
